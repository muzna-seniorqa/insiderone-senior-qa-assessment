# Insider QA Automation Assessment

## 📌 Overview
This repository contains:

1. UI Automation (Selenium + Python)
2. API Automation (Swagger Petstore)
3. Load Testing (Locust/JMeter)

---

## 🚀 UI Automation
- Website: https://insiderone.com
- Flow: Careers → QA jobs → filters → verify jobs → View Role
- Tech: Selenium, Pytest, POM

---

## 🔗 API Automation
- Swagger Petstore APIs tested
- Endpoints: Create, Read, Update, Delete Pet
- Tool: Postman
  
---

## ⚡ Load Testing
- Tool: JMeter
- Target: n11.com search
